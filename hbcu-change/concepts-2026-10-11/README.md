# HBCU Change — three revised landing-page concepts

[Download the complete concept set](https://github.com/TheTESTIMONY/AI-Code/raw/refs/heads/main/hbcu-change/concepts-2026-10-11/hbcu-change-concepts.zip)

Unzip the package and open **index.html** to compare the three revised concepts, switch preview widths, view the unchanged original and read both reviews. If your browser blocks local frames, use “Open full page” or open the individual HTML files directly.

| Concept | Direction |
| --- | --- |
| **Clear path** | Asymmetric structure, Outfit, a bright palette, expanding school journey and scroll-linked report/rollout. Recommended. |
| **In the flow** | Consistent dark palette, Satoshi with Manrope fallback, expanding journey, image scale/fade and word reveal. |
| **Shared future** | Warm paper, Newsreader with Geist, a centred campus opening, inline image typography and stacked rollout. |

All three retain the original opening and natural first-person proposal language. The substantive explanation, conditional claims and cost qualifications remain intact. FAQs are visible rows; the discussion questions now appear in-page, with carousel and full-list options.

Each concept is a standalone HTML file with embedded imagery, fonts and GSAP/ScrollTrigger. Studio optionally loads Satoshi from Fontshare; it uses embedded Manrope offline. Interactions include school identity switching, a four-step walkthrough, cost toggle, mobile navigation and global motion control. Device reduced-motion settings produce a static experience.

Read [revision and self-review](self-review.md) for the uploaded skills audit, corrections, evidence and limits. Read [reference design comparison](design-review.md) for the Calendly/CleanShot evaluation. Privacy and review notes are in notes.html. Dependency licences are included. The 404 file is ready for future host configuration; these files do not publish a live site.

Checks passed: DOM interactions with actual GSAP runtime, reduced-motion lifecycle, local links and IDs, original copy preservation, calculated palette contrast, headline font metrics and ZIP integrity. Browser visual inspection, screenshots, live overflow and real-device accessibility remain unverified because the supported browser tool was unavailable.

Images and records are conceptual. Prices come from the supplied proposal and were not independently verified. No live platform connection, payment, booking or message sending is implemented.
